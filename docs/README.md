# Bem-vindo à Wiki do HubAI 🚀

Este é o seu ambiente unificado de aprendizado e consulta! Construímos esta base de conhecimento para que você, sua equipe e seus clientes tenham um local centralizado para entender as mecânicas de **Dropshipping**.

Utilize o menu lateral esquerdo para navegar de forma rápida pelas documentações. Além disso, existe uma lupa de **Pesquisa (Search)** ali no topo caso você queira procurar uma palavra específica da sua dúvida rapidamente!

---

### O que você vai encontrar aqui?

* **Estrutura e Governança:** Como o servidor processa dados (Para a T.I).
* **Guia dos C-Levels (Admin):** Como você enxerga o painel central, gere taxas de assinatura e extrai relatórios financeiros.
* **Operação de Chão de Fábrica (Galpão):** Instruções de como enviar e transferir cargas parciais ou totais e bipar os códigos pelo Filament.
* **Guia Lojista Vendedor (Sellers):** Manual do seu cliente para ele plugar a conta Oauth Mercado Livre dele em 3 cliques.
